Connecting tablets

In the app's Settings, choose Jellyfin server, enter this server's address and tap Sign in with Quick Connect. Approve the code it shows from your profile menu → Quick Connect, signed in as any user (a user just for the tablets works well). An API key from Dashboard → API Keys works too. Tablets download everything they need, so they keep working with no connection during the game.
